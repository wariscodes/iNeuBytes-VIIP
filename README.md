# iNeuBytes VIIP Internship Projects

This repository contains the projects completed as part of the **iNeuBytes 45-Day Virtual Internship Immersion Program (VIIP)** in Artificial Intelligence.

## 📁 Projects

### Task 1: Image Classification using CNN
- **Dataset:** CIFAR-10
- **Technology:** Python, TensorFlow/Keras, CNN
- **Objective:** Build and evaluate a Convolutional Neural Network for classifying images into 10 categories.
- **Final Test Accuracy:** 70.10%

Folder: [`Task1/`](Task1/)

### Task 2: Sentiment Analysis
- **Dataset:** IMDb movie reviews
- **Technology:** Python, Scikit-learn, TensorFlow/Keras
- **Objective:** Classify movie reviews as positive or negative using machine learning and deep learning approaches.
- **Experiments:** Logistic Regression, SVM, and LSTM.

Folder: [`Task2/`](Task2/)

### Major Project: AirMate AI – Travel Chatbot
- **Technology:** Python, Flask, Scikit-learn, TF-IDF, Logistic Regression, HTML, CSS, JavaScript
- **Objective:** Build a travel-assistance chatbot that predicts user intents such as booking, cancellation, and changing a booking.
- **Backend:** Flask REST API
- **Frontend:** Web-based chat interface
- **Model Evaluation:** 99.64% validation accuracy on the prepared dataset.

Folder: [`Major-Project/`](Major-Project/)
